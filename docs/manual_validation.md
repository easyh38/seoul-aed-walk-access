# QGIS 수동 공간 검증 기록

- 검증일: 2026-11-27
- 검증 도구: QGIS 3.44.16 LTR
- 실행 환경: Ubuntu 26.04 LTS (WSLg)
- 분석 대상: 서울시 100m 격자 검증 지점
- 검증 표본: 20개

## 1. 검증 목적

DB에 저장된 격자별 2분·4분 보행 접근 가능 여부가
실제 등시선(GeoJSON) 다각형의 공간 판정과 일치하는지 확인한다.

## 2. 표본 선정 방법

재현 가능한 난수 시드
`aed-manual-validation-20261127-v1`을 사용했다.

19개 지점은 접근성 판정 유형별 층화 무작위 추출로 선정했다.

- 2분·4분 모두 접근 가능: 6개
- 4분만 접근 가능: 6개
- 2분·4분 모두 접근 불가: 7개

여기에 DB 판정의 역전 사례인 grid_id 21396을 추가해
총 20개를 검증했다.

따라서 이 표본은 단순 무작위 표본이 아니라
판정 유형을 구분한 층화 표본이며, 전체 모집단의 오류율을
추정하는 통계적 표본으로 사용하지 않는다.

## 3. QGIS 검증 데이터

다음 GeoJSON 파일을 불러왔다.

| 파일 | 용도 |
|---|---|
| validation_points.geojson | 검증 지점 20개 |
| isochrones_2min.geojson | 2분 등시선 |
| isochrones_4min.geojson | 4분 등시선 |
| nearby_aeds.geojson | 주변 AED 위치 |

레이어 순서는 다음과 같이 설정했다.

1. validation_points
2. nearby_aeds
3. isochrones_2min
4. isochrones_4min

2분과 4분 등시선은 서로 구분되도록 색상과 투명도를 조정했다.

- 선택 방식: Create new selection

DB와 GeoJSON 기반 사전 공간 검증의 40개 판정은 모두 일치했다.
QGIS 위치 기반 선택 결과도 전체 선택 개수와 역전 사례의
포함 여부가 예상 결과와 일치했다.

단, QGIS에서 선택된 7개 및 12개 전체 grid_id를 별도 파일로
내보내어 개별 대조한 것은 아니다. QGIS 검증은 선택 개수와
grid_id 21396의 포함 여부를 확인한 결과로 기록한다.

## 7. 검증의 한계

- 표본은 접근성 유형별 층화 표본이므로 전체 서울 격자의
  오분류율을 통계적으로 추정하는 데 사용할 수 없다.
- 등시선 다각형과 격자 지점의 공간적 포함 여부를 검증한 것이며,
  실제 현장 보행이나 AED의 실제 사용 가능 여부까지 검증한 것은 아니다.
- 지도 화면의 축척과 심볼 크기에 따라 경계 부근 점은
  다각형 안쪽처럼 보일 수 있으므로 시각적 확인만으로 판정하지 않는다.
- QGIS의 intersects 조건은 경계에 닿는 경우도 교차로 판정한다.
